  1. 즐겨찾기 줄을 켭니다. 크롬 주소창 아래에 즐겨찾기 줄이 안 보이면 Ctrl+Shift+B
  2. 아래 보라색 버튼을 마우스로 꾹 눌러 즐겨찾기 줄까지 끌어다 놓습니다.
    📋 마라톤 자막 가져오기← 이 버튼을 끌어서
    youtube.com/watch?v=…
    ★ 즐겨찾기 줄📋 마라톤 자막 가져오기⬆ 여기에 놓기
    유튜브 영상 화면
  3. 유튜브에서 수업 영상을 열고 즐겨찾기 줄의 「마라톤 자막 가져오기」를 누릅니다. 오른쪽 위에 「복사됐습니다 · n줄」이 뜨면 여기 AI 요약 칸의 붙여 넣기를 누르세요.
끌어다 놓기가 안 될 때 — 직접 추가하기
  1. 를 누릅니다.
  2. 즐겨찾기 줄의 빈 곳을 마우스 오른쪽 버튼으로 누르고 → 페이지 추가 (또는 Ctrl+Shift+O 즐겨찾기 관리자 → ⋮ → 새 북마크 추가)
  3. 이름: 마라톤 자막 가져오기 · URL: 칸을 비우고 Ctrl+V 로 붙여 넣기 → 저장

휴대폰 · 태블릿 · 다른 브라우저에서는 쓰지 않습니다. 자막이 없으면 「이 영상에는 자막이 없습니다」가 뜹니다 — 영상을 올린 직후면 잠시 뒤 다시 눌러 주세요.
