# 카카오 알림톡 붙이는 법 (솔라피)

코치룸 ④ 발송의 **[알림톡 보내기]**가 쓰는 설정입니다. 처음 한 번만 하면 됩니다.
키 값은 **Supabase Secrets 에만** 넣습니다. 이 저장소 · 카톡 · 메모 · 대화창에는 절대 적지 않습니다.

## 0. 준비물
- 카카오톡 채널(비즈니스 채널) — 학원 이름으로 된 채널. 채널 관리자 계정으로 로그인할 수 있어야 합니다.
- 솔라피(solapi.com) 회원 가입 · 결제 수단(충전)
- 발신번호 1개 (학원 전화번호) — 솔라피에서 **발신번호 등록**을 먼저 합니다(서류 인증이 있을 수 있음).

## 1. 카카오 채널 연동 → pfId 받기
1. 솔라피 콘솔 → **카카오톡 채널** (또는 「채널 연동」) → **채널 연동하기**
2. 채널 검색용 아이디(@로 시작)를 넣고, 관리자 휴대폰으로 온 인증번호를 넣습니다.
3. 연동이 끝나면 채널 목록에 **pfId**(채널 ID, `KA01PF…`처럼 생긴 값)가 보입니다. → 나중에 `SOLAPI_PFID` 에 넣습니다.

## 2. 알림톡 템플릿 등록 — 칸마다 넣을 것
솔라피 콘솔 → **알림톡 템플릿** → **템플릿 등록** (채널은 위에서 연동한 채널)

| 칸 | 넣을 것 |
|---|---|
| 템플릿 이름 | `주간레포트안내` |
| 카테고리 | 교육 쪽에서 가장 가까운 것 (예: 「교육 › 학습 안내」 「교육 › 수강 안내」처럼 보이는 항목 — 이름은 화면마다 조금 다를 수 있습니다) |
| 메시지 유형 | **기본형** (강조 표기 없음, 이미지 없음) |
| 본문 | `kakao/template.txt` 의 [본문] 세 줄을 줄바꿈까지 그대로 |
| 버튼 | **웹링크** 1개 — 버튼 이름 `레포트 보기` |
| 버튼 모바일 주소 · PC 주소 | 둘 다 `https://marathonstudy.github.io/marathon-hub/me/?c=#{코드}` |
| 변수 예시 (물어보면) | `#{이름}` 김하늘 · `#{수업일}` 10월 15일(목) · `#{코드}` AbCdEfGhIjKlMnOpQrSt12 |

- 변수 이름은 **정확히** `#{이름}` `#{수업일}` `#{코드}` 세 개여야 합니다(코치룸이 이 이름으로 채웁니다).
- 버튼 주소가 `/me/?c=…` 인 이유: 러닝노트 주소는 원래 `/me/#코드` 인데, `#` 이 알림톡 변수 표시(`#{…}`)와 겹칩니다. 그래서 `?c=` 로 열고, 러닝노트가 열리면 `#코드` 주소로 바꿉니다. 코치룸은 **학부모 링크 코드만** 넣습니다(학생 링크 아님).
- **검수 요청**을 누르면 카카오 심사(보통 1~3 영업일)가 시작됩니다. 반려되면 이유를 보고 문구를 고쳐 다시 요청합니다.
- 승인되면 템플릿 목록에 **템플릿 ID**(`KA01TP…`처럼 생긴 값)가 보입니다. → `SOLAPI_TEMPLATE_ID`

## 3. API 키 만들기
솔라피 콘솔 → **개발/연동** (또는 「API Key 관리」) → **새 API Key 만들기**
- **API Key** → `SOLAPI_API_KEY`
- **API Secret** → `SOLAPI_API_SECRET` (만들 때 한 번만 보입니다. 바로 Supabase 에 넣으세요)
- 허용 IP 를 정하는 칸이 있으면 비워 둡니다(Supabase 서버 주소가 바뀔 수 있음).

## 4. Supabase Secrets 다섯 개 넣기 (템플릿 승인 뒤)
Supabase 대시보드 → **Edge Functions** → **Secrets** → **Add new secret**

| 이름 | 값 |
|---|---|
| `SOLAPI_API_KEY` | 3의 API Key |
| `SOLAPI_API_SECRET` | 3의 API Secret |
| `SOLAPI_PFID` | 1의 pfId |
| `SOLAPI_TEMPLATE_ID` | 2의 템플릿 ID |
| `SOLAPI_SENDER` | 솔라피에 등록한 발신번호 (숫자만, 예: 0212345678) |

넣은 뒤 코치룸 「오늘」 → **[설정]** 의 「카카오 알림톡」 칸에서 다섯 개가 모두 ✓ 인지 봅니다(키 값은 보이지 않습니다).

## 5. 처음 보내기 전에
1. **[설정]** → 「내 시험 번호」에 내 휴대폰 번호 → **[내 번호 저장]**
2. ④ 발송 → 주차 고르기 → **[나에게 시험 발송]** → 내 카톡에 알림톡이 오는지, **[레포트 보기]** 를 누르면 그 학생 러닝노트가 열리는지 확인
3. 괜찮으면 **[알림톡 보내기 (n명)]** → 「n명에게 알림톡을 보냅니다. 예상 비용 약 n원」 확인

## 알아 둘 것
- 알림톡을 못 받는 사람(카톡 미사용 등)에게 **문자로 대신 보내기**는 기본으로 꺼져 있습니다. [설정]에서 켤 수 있고, 켜면 그만큼 문자 요금(건당 대략 45원)이 더 듭니다.
- 같은 학생 · 같은 주에 이미 보낸 학생은 다시 보내지 않습니다. 꼭 다시 보내야 하면 그 학생 줄의 **[알림톡 다시 보내기]** (한 번 더 확인합니다).
- 한 번에 100명, 하루 최대 건수(기본 300건, [설정]에서 변경).
- 코치룸은 「솔라피가 받았다(접수)」까지만 바로 알 수 있습니다. 실제로 도착했는지는 솔라피 콘솔의 **발송 내역**에서 봅니다.
- 요금 · 메뉴 이름은 솔라피 사정에 따라 바뀔 수 있습니다. 1건 예상 비용은 [설정]에서 고칠 수 있습니다(기본 13원).
